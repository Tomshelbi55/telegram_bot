# ربات قرآن کریم (Aiogram 3 Async)

ربات تلگرام برای ارسال آیات قرآن (رندوم یا مشخص) با متن عربی + ترجمه فارسی و انگلیسی.

## اجرا روی سرور (Runflare یا مشابه)

### ۱) نصب وابستگی‌ها
```
pip install -r requirements.txt
```

### ۲) تنظیم متغیرهای محیطی (Environment Variables)

| متغیر | اجباری | توضیح | مثال |
|---|---|---|---|
| `BOT_TOKEN` | ✅ بله | توکن ربات از BotFather | `123456789:AAE...` |
| `ADMIN_IDS` | خیر (ولی توصیه می‌شود) | آی‌دی عددی ادمین‌ها با کاما جدا شود | `123456789,987654321` |
| `RATE_LIMIT_SECONDS` | خیر | فاصله مجاز بین درخواست‌های هر کاربر | `3` |
| `DB_FILE` | خیر | نام فایل دیتابیس | `bot_data.db` |
| `CONFIG_FILE` | خیر | نام فایل تنظیمات | `bot_config.json` |

### ۳) اجرا
```
python bot.py
```

## نکته امنیتی مهم

**هرگز** توکن ربات را داخل کد یا هیچ فایلی که به گیت‌هاب push می‌شود ننویس.
همیشه از Environment Variables استفاده کن (در پنل Runflare یا هر پلتفرم دیگر).

اگر توکن قبلاً جایی درز کرده، فوراً در BotFather با `/revoke` باطلش کن و توکن جدید بگیر.
